# 🤗 Emotional Buddy AI

An intelligent emotional support chatbot with advanced emotion detection and personalized mental health solutions.

## 🌟 Features

- Advanced emotion detection (sad, anxious, angry, stressed, lonely, happy)
- Personalized mental health solutions
- Real-time sentiment analysis
- Beautiful responsive web interface
- Crisis resources and support

## 🚀 Live Demo

[Visit the live app here](https://emotional-buddy-ai.onrender.com/)

## 🆘 Crisis Resources

- **US:** Call/Text 988 (Suicide Prevention Lifeline)
- **US:** Text HOME to 741741 (Crisis Text Line)
- **International:** befrienders.org

## 💡 How It Works

1. Share your feelings with the AI
2. AI detects your emotion and intensity
3. Receive personalized coping strategies
4. Get immediate, short-term, and long-term solutions

## 📝 Tech Stack

- Python Flask
- SQLAlchemy
- TextBlob & VADER (NLP)
- Vanilla JavaScript
